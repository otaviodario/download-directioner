Filter Guide

• Extension: Filters by ending (.zpl, .pdf, .txt).

• MIME Type: Sent by the server. Useful for dynamic downloads without extension in the link. (Optional)

• Filename: Distinguishes files of the same type (e.g. only files containing "danfe_").

• Origin: Filters downloads coming from specific domains (e.g. bling.com.br).
